# React 19 readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The page editor and the two admin screen templates start the same way on React 18 and React 19, and the rules forbid the APIs React 19 dropped.

**Architecture:** The only React 18-only code is the `render()` fallback in three mount points. `createRoot` has existed in `wp.element` since WordPress 6.2 and in ReactDOM 18, so the fallback is dead on every version we support and is removed rather than kept behind a check. A console-error guard in the editor's Playwright suite turns a React warning into a failure.

**Tech Stack:** plain JS (`wp.element`), node:test, Playwright.

**Spec:** bluegroup_core_foundation#98.

## Global Constraints

- No `package.json`, no build step, no JSX anywhere in this repo.
- The editor file must still load under `node --test` with no window.

## Review Focus

- A site on WordPress older than 6.2 has no `createRoot`: unsupported, and the editor will throw. Pinned by the node test that the file calls `createRoot` only.
- A React warning in the editor appears only in the console: pinned by the Playwright console guard.
